# BGMファイルの置き場所

Mureka AI などで生成した曲を、以下のファイル名で **このフォルダにそのまま置く** と、ゲーム内の「🎵 BGM選択」パネルに自動で反映されます（`js/bgm.js` の `BGM_TRACKS` にファイルパスが登録済みのため、追加コード不要）。

| ファイル名 | 曲の用途 | ゲーム内表示名 |
|---|---|---|
| `menu.mp3` | タイトル・モード選択画面 | メインテーマ |
| `normal.mp3` | 通常対局（ノーマル/ランダムブロックなど） | 対局(ノーマル) |
| `tense.mp3` | ミゼール/タイムアタックなど緊張感のあるモード | 緊迫(ミゼール/タイムアタック) |
| `playful.mp3` | ワイルド/重ね取りなど遊び心のあるモード | コミカル(ワイルド/重ね取り) |
| `gravity.mp3` | 重力モード専用 | 重力モード |
| `victory.mp3` | 勝利時の短いジングル | 勝利ジングル |
| `draw.mp3` | 引き分け時の短いジングル | 引き分けジングル |
| `lose.mp3` | 敗北時の短いジングル | 敗北ジングル |

## 曲を追加でどんどん増やしたい場合

1. `js/bgm.js` の `BGM_TRACKS` 配列に `{ id, title, desc, file }` を1行追加
2. 対応する mp3 をこのフォルダに置く

これだけで選択肢が増える（`assets/bgm/xxx.mp3` という命名で揃えると管理しやすい）。

## 未配置のファイルについて

まだ置かれていない曲を選んでも、ゲームがエラーで止まることはありません。トースト通知で「まだ準備されていません」と表示され、🚫 マーク付きで一覧に表示され続けます。
